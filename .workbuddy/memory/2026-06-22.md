# 2026-06-22

## GitHubSync 三项修复

1. **changelog.md 不再进入 Git 历史**：在 `sync()` 中 `git add .` 后调用 `_exclude_from_index("changelog.md")` 排除索引（已跟踪则 `git rm --cached`，未跟踪则 `git reset HEAD`）；同时在 `create_ignore()` 默认内容加入 `changelog.md`，并通过 `_ensure_gitignore_entry()` 补全已有 .gitignore。`updated_items` 循环也跳过 changelog.md。根因：之前 changelog.md 被 commit+push 到远程，恢复模式 reset --hard 时带回了本应临时发布即删除的文件。

2. **选中项高亮改为反色**：`STYLE_SELECTED` 从 `bgcolor=#31748F, color=#CDD6F4` 改为 `bgcolor=#CDD6F4, color=#11111B`（浅底深字）；app.py 中模式指示器 `style_sel`、选中忽略文件样式、操作按钮样式同步改为反色，操作文字用深色（删除 `#D20F39`、推送/恢复 `#40A02B`）保证可读性。

3. **推送模式右键切换操作按钮**：`handle_key()` 的 `KEY_RIGHT` 分支增加 `mode==0 and mode_locked` 时设 `action_index=1`；`KEY_LEFT` 分支增加推送模式锁定后 `action_index=0` 重置焦点。与恢复模式操作一致。

同步更新了 AGENTS.md 代码架构（新增 `_ensure_gitignore_entry`、`_exclude_from_index` 方法说明，更新 `sync()`、`create_ignore()`、`handle_key()` 描述）和 changelog.md（修复+优化）。
